# Eustratius Paper — Code & Results (release)

Companion material for the DH paper draft
*"Eustratius' Implicit Authority in the Twelfth-Century Aristotelian Commentary"*
(the pilot case studies on Proclus → Eustratius and Psellos → Eustratius).

This directory bundles the **analysis pipeline code**, the **results the paper cites**, and the
**match data** needed to reproduce every number. It does **not** contain the *source-corpus
texts* (TLG / OCR / open-TEI originals) — those are licensed and stay out of this archive. The
data included here are the pipeline's own match outputs (`text_reuse_matches.ndjson`,
`byz_byz_tagged.{ndjson,tsv}`), which are exactly the inputs `compute_reported_numbers.py`
reads.

## Reproducibility

The release is **self-contained**: all inputs the script reads are shipped under `logs/`.
From the repository root, just run:

```bash
python3 scripts/compute_reported_numbers.py   # writes results/reported_numbers.json
```

It has **no external dependencies** (standard library only) and records input SHA-256
hashes + run timestamp in its output. The packaged `results/reported_numbers.json` was
generated by a run from inside this release whose output matched every figure in
`Technical_Corrections_2026-08-07.md` (35,753 raw; 6,426/6,273/23,054 partition;
11,487 tagged = 39.2%; WP 7+14+678+4,561 = 5,260; chain < 6 = 86.3%; WP4 BYZ-BYZ ↔ chain ≥ 6
cross-check ✓).

**Input hashes of the generating run:** see `results/reported_numbers.json` → `metadata`
(`ndjson_hash = dc168b1017fb4ab4`, `filter_hash = 69b1f3462c91c323`).

## Provenance notes that matter for the paper

- **Match IDs** are the 1-based positions of records in `text_reuse_matches.ndjson` — so any
  ID (e.g. the Case B anchor **28636**, recurrences **28637/28638**) is recoverable from the
  archive by position.
- **Case A (Proclus → Eustratius *In EN* I):** 94 raw matches, 5 with chain ≥ 6. The pair is
  BYZ–ANC and therefore *outside* the BYZ–BYZ Topos Exclusion Matrix scope — all 94 records
  are `tag=''`. Consequence: the earlier "residual ancient-commonplace rate of 12%"
  (and "the Matrix removes shared-Aristotelian overlap") is **not supported by the data** and
  was dropped in favor of a data-backed formulation (see `Technical_Corrections_2026-08-07.md`
  §5.3 and `Reply_to_Jonathan_2026-08-29.md` §4).
- **Case B (Psellos *Theol.* I → Eustratius *In APo* II /82#3):** anchor `28636`, untagged
  (`tag=''`), i.e. a clean intra-Byzantine candidate — **not** a restored commonplace. This is
  the empirical basis of §5.4's "exclusion cannot be absolute".
